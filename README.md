One word, the first that comes to mind, for the "One Word, First Thought" bounty on make.fun. The program writes a single word to `/output/entry.txt`, where the judge compares it head to head with the other entries.

## Run it

```sh
python3 main.py
```

That writes the word to `/output/entry.txt`.
